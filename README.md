## 👩‍💻 About Me

I am a Computer Science graduate and I recently completed my Master's in **Security and Applied Logic** at the **University of Bucharest**, based in Bucharest, Romania.

My main interests are **AI/ML**, **Natural Language Processing**, **Computer Vision**, **cybersecurity**, **reverse engineering**, **secure software development**, and **backend engineering**.

My Master's dissertation focused on applying **Machine Learning and NLP techniques to SQL Injection detection**, using multiple text embedding techniques and classification algorithms.

I also have hands-on experience with **Computer Vision**, including image processing, feature matching, object detection, geometric transformations, and multi-camera object tracking using technologies such as **OpenCV, SIFT, RANSAC, YOLO11x, Kalman filtering, and the Hungarian algorithm**.

I achieved **19th place in Nitro Language Processing – 3rd Edition: Satire**, working on a Romanian-language binary text classification task, and **13th place at the 4T$ CTF competition**, where I worked on security-oriented challenges and Python tooling.

On the cybersecurity side, I have hands-on experience with web application security testing, vulnerability analysis, CTF challenges, low-level security labs, and reverse engineering practice. I have worked with topics such as **SQL Injection**, **XSS**, **Command Injection**, authentication and authorization issues, buffer overflows, shellcoding, Return2Libc, ROP, ASLR/PIE, stack canaries, and binary analysis.

I also completed a reverse engineering repository where I practiced binary inspection and analysis using tools such as **Ghidra**, **IDA**, **x64dbg**, and **radare2**.

Alongside AI and security, I have built full-stack and backend projects using technologies such as **Java Spring Boot**, **ASP.NET**, **Node.js**, **Express**, **React**, **GraphQL**, **SQL databases**, **JWT**, and **OAuth2**.

## 🧠 UniEmbed for SQLi — Master's Dissertation

**Machine Learning model for SQL Injection detection using text embeddings**

A research-oriented project developed as part of my Master's dissertation, focused on applying **Machine Learning and NLP techniques to SQL Injection detection**.

The project reproduces and evaluates an embedding-based classification pipeline and integrates the trained detector into real-world vulnerable applications.

**Tech Stack:**  
Python · scikit-learn · TensorFlow Hub · Word2Vec · FastText · Universal Sentence Encoder · NLP · Docker

**Highlights:**

- Built a **712-dimensional feature representation** combining:
  - Word2Vec — 100 dimensions
  - FastText — 100 dimensions
  - Universal Sentence Encoder — 512 dimensions
- Evaluated multiple classifiers:
  - Logistic Regression
  - SVM
  - Gaussian Naive Bayes
  - Decision Tree
  - KNN
  - MLP
  - Random Forest
  - Voting ensembles
- Achieved approximately:
  - **99.23% test accuracy**
  - **99.12% F1-score**
  - **99.86% ROC-AUC**
- Integrated the trained detector into Docker-based **Focalboard** and **AVideo** case studies
- Tested application behavior with and without SQL Injection detection enabled

🔗 [Repository](https://github.com/Lung-Alexandra/UniEmbed_SQLI)
